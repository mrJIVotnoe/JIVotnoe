We establish a strict hierarchy of data validity to prevent hallucination and false positives.

1.  **Truth 1st Order (The Metal):** Data from the Core/Modem (Raw Physics). *Incontestable.*
2.  **Truth 2nd Order (The Child/User):** Aggregated User Observations. *Vital Context.*

3.  **Truth 3rd Order (The AI):** Inference and Logic. *Advisory Only.*
