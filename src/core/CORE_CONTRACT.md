# CORE_CONTRACT.md

> Версия: v0.1 (fact-based)
> Статус: CONTRACT (не манифест)

---

## 1. Назначение Core

Core — это **чистый логический слой**, предназначенный для:

* приёма формализованных входных данных от UI / AI / внешних адаптеров;
* вычисления рекомендаций, состояний или решений;
* возврата **структурированного результата**, не зависящего от UI.

Core **не отвечает** за:

* визуализацию;
* сетевые запросы;
* хранение ключей;
* прямое взаимодействие с AI.

---

## 2. Гарантии (подтверждённые кодом / структурой проекта)

### G-001. Изоляция от UI

Core не импортирует UI-компоненты.

**Статус:** VERIFIED (`src/core/index.ts` has no React imports)

---

### G-002. Изоляция от сети

Core не содержит HTTP / fetch / websocket вызовов.

**Статус:** VERIFIED (Analysis functions are pure)

---

### G-003. Отсутствие визуализации

Core не рендерит и не форматирует UI-данные.

**Статус:** VERIFIED

---

## 3. Входы Core

На текущий момент Core принимает входные данные в виде:

* plain TypeScript-объектов (`DecisionInput`);
* без прямой привязки к DOM, window или платформе.

**Тип:** `DecisionInput` (defined in `src/core/domain/types.ts`)

---

## 4. Выходы Core

Core возвращает:

* структурированные объекты с результатом вычислений (`DecisionResult`);
* данные, пригодные для отображения или дальнейшей интерпретации.

**Тип:** `DecisionResult` (defined in `src/core/domain/types.ts`)

---

## 5. Decision Engine

На текущий момент **явно выделенного класса Decision Engine нет**.

Имеется:

* распределённая логика принятия решений внутри функций `decideStrategy` и `analyzeEnvironment`.

**Следствие:**

* утверждения White Paper о монолитном Decision Engine реализуются через композицию функций.

---

## 6. AI-взаимодействие

AI:

* вызывается вне Core (`src/features/ai`);
* передаёт результаты в Core только через явные структуры данных (mapping logic in Store);
* не имеет прямого доступа к состоянию Core.

**Статус:** VERIFIED

---

## 7. Запреты (жёсткие)

Core **НЕ ИМЕЕТ ПРАВА**:

* импортировать UI / React;
* выполнять сетевые запросы;
* хранить или использовать API-ключи;
* вызывать AI напрямую.

Нарушение любого пункта = архитектурная ошибка.
